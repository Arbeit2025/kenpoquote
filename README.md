# kenpoquote

日本国憲法の全文（前文＋全103条）から、条文を引いて引用できるツール。

## 機能
- トップページでランダムに1条を表示
- 条番号ページ（`/article/<番号>`）・前文ページ・全文ページ（章立て表示）
- キーワード検索（条文中の語句、条番号でも検索可）
- 各条に「引用文をコピー」ボタン（見出し＋本文＋出典のプレーンテキスト）
- JSON API：`/api/random`、`/api/article/<番号>`

## データについて
- 条文データの出典は e-Gov法令検索「日本国憲法（昭和二十一年憲法）」。
- 法令の条文は著作権法第13条により著作権の対象外。
- 条文は公布時の歴史的仮名遣い・旧字体のまま収録している。

## 動かし方
```bash
pip install -r requirements.txt
python app.py
```
